# purpur — design and provenance

purpur is an original, open implementation of a push-to-talk voice-typing assistant
for macOS, built after a static reverse-engineering study of **Wispr Flow v1.6.1174**.
It contains **no code, assets, or text copied** from that product. All implementation
here is newly written; all icon and sound assets are generated by `scripts/gen-assets.js`.

Observed architecture (all static; the app was never executed):

| Area | Observed in Wispr Flow | purpur design |
|---|---|---|
| Shell | Electron 42 + React renderers (`hub`, `overlay`, `scratchpad`, `meeting_ax_inspector` entries); main bundles under `.webpack/main` | Electron, plain-HTML renderers: `pill` (overlay) + `settings` (control window) |
| Global trigger | Separate Swift `LSUIElement` helper (`accessibility-mac-app`) importing `CGEventTapCreate`, `CGEventSourceFlagsState`, `IOHIDManager` | `helper/main.swift`: CGEventTap on `flagsChanged`/`keyDown`; Fn hold/double-tap and right-Option hold; Electron `globalShortcut` as fallback |
| Insertion | `@wispr/panel-activation` native addon; AX APIs in helper (`AXUIElementSetAttributeValue`, `CGEventPost` Cmd+V) | Helper inserts via `kAXSelectedTextAttribute`, falls back to clipboard + synthetic Cmd+V |
| Context | AX reads of focused element (`AXUIElementCopyAttributeValue`, text markers); "shouldSaveAxText" history flag; ax-inspect traces | Helper `context` request: frontmost app, focused role/title/selected text (truncated), passed to cleanup prompt only |
| Audio | `opusscript` + `incrementalOpusEncoder.worker.js` streaming encode | Renderer captures 16 kHz mono PCM via AudioWorklet, main assembles WAV (no native deps) |
| Transcription | Proprietary cloud streaming STT | Pluggable: any OpenAI-compatible `/audio/transcriptions` endpoint, or a local `whisper.cpp` CLI; `mock` provider for demo |
| Post-processing | Cloud LLM cleanup with tone/style | Optional OpenAI-compatible chat-completions cleanup; dictionary substitutions always applied locally |
| Storage | `flow.sqlite` (sqlite3 + sequelize/umzug), `electron-store` settings | JSON stores (`settings.json`, `history.json`) — no native modules |
| Extras (not rebuilt) | Meeting notes via system-audio capture (`NSAudioCaptureUsageDescription`), Jabra/BLE-ring integration, MediaRemote pause, MCP agent bridge, Sentry/PostHog/WorkOS | Explicitly out of scope for v1 |

## purpur data flow

```
hotkey ──> helper (CGEventTap) ──stdout JSON──> main
   main ──IPC──> pill window (shown, level meter, live text)
   pill (AudioWorklet 16 kHz) ──PCM frames──> main (WAV buffer, partials)
   stop ──> main: WAV → STT provider → dictionary → cleanup prompt → text
   text ──> helper `insert` (AX, else clipboard paste) ──> focused app
   entry ──> history.json;  pill shows result, hides
```

## Fidelity notes

- The pill is non-focusable and always-on-top so the target app keeps focus —
  matching the observed overlay behavior.
- Partial (live) transcripts are sent only when the selected provider is
  OpenAI-compatible and the setting is on; local whisper runs on stop only.
- Permissions mirror the observed set: Microphone, Accessibility, Input
  Monitoring; the helper reports status and Settings opens the right panes.
